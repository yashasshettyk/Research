# Topic options, set 12: pure DL/ML research (2026-11-09)

She prefers DL/ML projects; disliked sets 8–11. Priority = publish a paper. These are ML *method* topics: run on free Colab with public datasets (CIFAR, etc.), improve a known method, publish.

| # | Idea | Plain meaning |
|---|---|---|
| 1 | **Learning with noisy labels** | Train well even when many training labels are wrong |
| 2 | **Continual learning** | Model learns new things without forgetting old ones (catastrophic forgetting) |
| 3 | **Test-time adaptation** | Model adjusts itself when real data changes (night, rain, blur) |
| 4 | **Knowledge distillation for phones** | Shrink a big model into a small fast one with little accuracy loss |

## Recommendation
**#1 Noisy labels.** Easy start on public datasets, clear experiments, many venues; real Indian datasets are often crowd-labelled and messy.
