# Project idea 1 — Fake news detection in Kannada (low-resource language)

**Title:** Detecting misinformation in Kannada social media posts using lightweight multilingual language models

**Problem statement:**
Fake news spreads fast on WhatsApp and social media in Indian regional languages like Kannada.
Most detection tools are built for English and perform poorly on Kannada, because there is little
labelled Kannada data. There is a need for an accurate, low-cost method to detect fake news in
Kannada that can run on limited hardware.

**Objectives:**
1. Build/collect a small labelled dataset of Kannada real vs fake news.
2. Compare multilingual models (e.g. MuRIL, IndicBERT, XLM-R) for the task.
3. Improve accuracy with data augmentation (e.g. translation from English datasets).
4. Make a lightweight model that runs on a normal laptop/phone.

**Why it suits M.Tech:** real social problem, clear gap (low-resource language), doable in ~1 year, publishable.
