# Conversation log

One file per month: `YYYY-MM.md`. Each entry records what Shravya asked and what came of it.

Entry format:
```
## YYYY-MM-DD — <short title>
- **Asked:** <her question/request, one line>
- **Answer/outcome:** <key points, 1–3 lines>
- **Files:** <files created/changed, if any>
- **Follow-up:** <open items, if any>
```
