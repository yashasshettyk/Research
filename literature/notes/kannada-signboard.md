# Kannada sign-board reader: prior work (searched 2026-11-09)

Verdict: already done in parts by Indian student/college projects, so it is NOT new as-is.

- Traffic Signboard Recognition and Text Translation System using Word Spotting and ML. ITM Web of Conferences 50 (2022). Kannada road signs → English, CNN; ~95–97% reported. https://www.itm-conferences.org/10.1051/itmconf/20225001010
- A Translator for Indian Sign Boards to English using Tesseract and SEQ2SEQ (Christ University). https://archives.christuniversity.in/items/show/10851
- Kannada Text to Speech Conversion System (IJITEE): OCR of printed Kannada → speech. https://ijitee.org/?p=7654
- Signboard Text Translator: A Guide to Tourist (IJECE, Telugu). https://ijece.iaescore.com/index.php/IJECE/article/view/8212
- KSCST student project on sign boards. https://www.kscst.org.in/spp/45_series/SPP45S/01_Seminar_Projects/098_45S_BE_4313.pdf

Possible new angle (to verify): messy real shop boards (painted/handwritten, mixed Kannada+English, night/blur), fully offline on a cheap phone, plus a new public dataset.
